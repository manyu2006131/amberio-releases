2D 横版皇城动作游戏：从地牢醒来，穿过皇城各层，挑战国王，摘冠登基。

## 下载

## 资源保护与验证

- 使用自编译的 Godot 4.7.2 导出模板，两端各 1060 项导出资源与目录索引启用 AES-256 加密。
- 已核验加密标记、解密完整性和错误密钥拒绝；发布页提供检查记录及 SHA-256 清单。
- 安卓沿用原应用标识和签名，版本代码提升至 22。
- 工程自动流程、导出资源加载、键盘改绑和模拟多点触控检查通过。
- **尚未完成 Windows 物理设备和安卓实机的全流程、性能与机型兼容性验证，以预发布测试版提供。**
- 加密只能提高资源提取难度，不能保证无法逆向，也不能阻止截图或录音。
